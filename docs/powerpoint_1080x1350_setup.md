# PowerPoint Setup for 1080 × 1350 LinkedIn Portrait Image

Use this setup when creating a LinkedIn portrait post image in PowerPoint.

## Slide Size

1. Open **PowerPoint**
2. Go to **Design**
3. Click **Slide Size**
4. Select **Custom Slide Size**
5. Set the size to:

```text
Width: 10.8 in
Height: 13.5 in
```

6. Choose **Portrait**
7. Click **OK**
8. Select **Ensure Fit**

## Why This Works

LinkedIn portrait image size:

```text
1080 × 1350 pixels
```

This has a **4:5 aspect ratio**.

PowerPoint uses inches instead of pixels, so:

```text
10.8 in × 13.5 in
```

keeps the same **4:5 ratio**.

## Exporting the Image

After designing the slide:

1. Go to **File**
2. Click **Export**
3. Choose **PNG** or **JPEG**
4. Select **Just This One**

## Recommended Use

Use this format for:

- LinkedIn technical carousel-style images
- DevOps/SRE visual posts
- Architecture snippets
- Terminal screenshot posts
- 4:5 portrait social media graphics

## Note

PowerPoint may not always export exactly `1080 × 1350` pixels by default, but the image will keep the correct LinkedIn portrait ratio.

If exact pixel export is needed, resize the exported image later to:

```text
1080 × 1350 px
```
